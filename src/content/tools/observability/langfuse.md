## 定位

Agent 可观测性领域最活跃的开源工具之一，支持 OpenTelemetry 集成，帮助开发者诊断 Agent 的语义级故障。

## 为什么传统监控不够

Agent 故障是轨迹级和语义级的：涉及意图、约束、工具使用顺序、决策推理。所有工具调用可能返回成功状态码，但 Agent 的行为仍然是错误的。LangFuse 等 AgentOps 平台试图弥合这个语义鸿沟。
