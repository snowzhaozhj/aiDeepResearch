Inspect AI

英国 AI 安全研究所（AISI）和 Meridian Labs 共同开发的评估框架。200+ 预构建任务，内置 Agent 工作流支持，Docker/K8s 沙箱隔离。

HIGH ACTIVE 评估体系 GitHub → agent-评估 安全 沙箱

为什么值得关注

在 LLM 评估工具中，Inspect AI 占据了一个独特的位置：它不仅是评估框架，更是 Agent 行为的安全测试平台。当你需要在沙箱环境中验证 Agent 是否会做出危险操作时，这是目前最成熟的选择。

关键洞察

Inspect AI 的核心价值不在于基准测试数量，而在于它的 Agent 工作流原生支持：内置 ReAct 和 Deep Agent，可以桥接 Claude Code、Codex CLI、Gemini CLI，在 Docker/K8s 沙箱中安全执行。

核心能力

  • 200+ 预构建评估任务，覆盖安全、推理、编码
  • 广泛的模型支持：OpenAI / Anthropic / Google / vLLM / Ollama
  • Agent 原生：内置 ReAct、Deep Agent，支持多步骤 Agent 工作流评估
  • 沙箱隔离：Docker 和 K8s 原生支持

适用场景

场景适合度说明
AI 安全评估最佳专为安全评估设计，AISI 背书
Agent 能力测试最佳内置 Agent 工作流，沙箱隔离
标准学术基准可用任务丰富但不如 lm-eval-harness 全面
CI/CD 集成可用支持但不如 DeepEval 的 pytest 集成顺滑
实践建议

不要试图用一个框架覆盖所有评估需求。常见组合：Inspect AI 做 Agent 安全评估 + lm-eval-harness 做标准基准 + DeepEval 做日常 CI 回归。

置信度说明

本分析基于官方文档、GitHub 仓库和多个独立源交叉验证，置信度为 HIGH。核心能力声明均经主源确认，Agent 桥接功能获 2-1 验证通过。

lm-evaluation-harness

EleutherAI 出品的 LLM 评估框架。Hugging Face Open LLM Leaderboard 的后端引擎，被数百篇学术论文引用的事实标准。

HIGH ACTIVE 评估体系 GitHub → ★ 12.8k 学术标准

为什么是事实标准

如果你在写论文或者做模型排名，绑不开 lm-evaluation-harness。它是 Hugging Face Open LLM Leaderboard 的后端引擎，内置 60+ 标准基准（MMLU、HellaSwag、GSM8K、BBH 等）。数百篇论文引用意味着你的评估结果可以直接与已发表的工作对比。

关键洞察

lm-eval-harness 的真正壁垒不是功能，而是 生态位：当整个学术界都用它作为基准，你的评估结果天然具有可比性。这种网络效应让竞争者很难替代它。

适用场景

场景适合度说明
学术论文基准对比最佳事实标准，结果可直接比较
模型排行榜最佳HF Leaderboard 后端
自定义评估任务最佳社区任务生态最丰富
Agent 评估不适合面向静态模型，无 Agent 支持
